Two lines to your past self — a make.fun bounty entry. A tiny Python
script (stdlib only, no network) that writes the two-line entry text to
`/output/entry.txt`, byte-exact, with no trailing newline, and verifies
the written bytes with a read-back check.

## Run

```sh
python3 main.py
```

This writes `/output/entry.txt` and prints its sha256.
